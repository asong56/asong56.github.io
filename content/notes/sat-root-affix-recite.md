# SAT 词根词缀速背手册

> **版式原则：一根一行，四栏固定。**

## 使用方法

每行固定按 **词根/词缀 → 核心义 → 语义演变 → 例词** 阅读。第一遍只看「词根 + 核心义」；第二遍遮住核心义回忆；第三遍用例词验证演变逻辑。助记线索（💡）用于词根不直观时，可选读。

## 栏目说明

| 栏目 | 含义 |
|---|---|
| 词根/词缀 | 本手册采用的标准写法；同源异形用 `/` 列出 |
| 核心义 | 最小、最稳定的词源语义（英文） |
| 语义演变 | 词源义到现代词义的真实跳跃路径；纯翻译义省略 |
| 例词 | 真实单词中的形态；难词附中文注释 |

# 1. 否定、缺失与相反

| **`contra-, counter-`** | against; opposite; in response to |  | contradict, contravene（违反）, counteract, countervailing（抵消的） |
| **`neg-`** | deny; say no; nullify |  | negate, negative, abnegation（克己、放弃） |
| | | 💡 想到 negate，neg- 就是那个"说不"的动作 | |
