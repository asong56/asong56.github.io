SAT 词根填空版

使用方法：遮住「核心义」和「例词」列，只看词根，默想答案再揭开核对。
第一轮只填核心义；第二轮只填例词；第三轮两者都填。

A. 否定与缺失

词根 核心义（遮住后填写） 至少两个例词（遮住后填写）
neg- say no / deny / nullify negate、negative、abnegation、renegade……
nihil- nothing / zero nihilism、annihilate、nil……

B. 运动与路径

词根 核心义（遮住后填写） 至少两个例词（遮住后填写）
ced-/cess- go / move / yield precede、recede、secede、concede……
fug-/fugit- flee / escape fugitive、refuge、refugee、subterfuge……
sal-/sil-/sult- leap / jump salient、resilient、resilience、exult……
curr-/curs-/cour- run / flow rapidly current、cursor、cursory、precursor……

C. 抓取与持有

词根 核心义（遮住后填写） 至少两个例词（遮住后填写）
cap-/cept-/cip- take / seize / receive capture、concept、intercept、recipient……
ten-/tain-/tin- hold / keep / maintain retain、contain、sustain、tenacious……
greg- flock / herd / group aggregate、congregate、segregate、egregious……
haer-/hes- stick / cling adhere、inherent、coherent、cohesive……

D. 说话与声音

词根 核心义（遮住后填写） 至少两个例词（遮住后填写）

loqu-/locut- speak / talk eloquent、eloquence、colloquial、colloquium……
tac-/tic- silent / be silent tacit、taciturn、reticent、reticence……

E. 看与判断

词根 核心义（遮住后填写） 至少两个例词（遮住后填写）
spec-/spect-/spic- look / observe / see inspect、perspective、circumspect、conspicuous……
cern-/cret-/crit- separate / distinguish / judge discern、discerning、discrete、discreet……
cogn-/gnos- know / recognize cognition、recognize、agnostic、diagnose……

F. 情感与意志

词根 核心义（遮住后填写） 至少两个例词（遮住后填写）
path-/pathy- feeling / suffering empathy、sympathy、apathy、antipathy……
fid- faith / trust fidelity、confident、confide、perfidious……
anim- breath / spirit / life-force animate、inanimate、magnanimous、pusillanimous……
plac-/pleas- please / calm / satisfy placid、placate、implacable、complacent……

G. 善恶与法律

词根 核心义（遮住后填写） 至少两个例词（遮住后填写）
sanct- holy / sacred / inviolable sanctity、sanction、sanctimonious、sanctuary……
ver- true / truth verify、veracity、veracious、verdict……
culp- fault / blame culpable、culprit、exculpate、inculpate……

H. 形态与变化

词根 核心义（遮住后填写） 至少两个例词（遮住后填写）
vert-/vers- turn convert、divert、avert、revert……
plic-/plex-/pli- fold / bend / intertwine complicate、implicit、explicit、perplex……

I. 生命与身体

词根 核心义（遮住后填写） 至少两个例词（遮住后填写）

L. 制作与力量

词根 核心义（遮住后填写） 至少两个例词（遮住后填写）

M. 高级词汇专项

词根 核心义（遮住后填写） 至少两个例词（遮住后填写）
sed-/sid-/sess- sit / settle sedentary、reside、preside、president……
limin-/limen- threshold / boundary preliminary、subliminal、eliminate、liminal……
rog- ask / request interrogate、arrogant、arrogate、derogate……

oner- burden / load onerous、exonerate、onus……

检查标准

  • 核心义：英文关键词说对即可，不要求一字不差
  • 例词：说出任意两个即算通过
  • 进阶：能说出词根拆解逻辑
