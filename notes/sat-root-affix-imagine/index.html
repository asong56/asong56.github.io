SAT 词根联想手册

每个词根是一个轴心，向外辐射出所有相关单词。
先读「轴心 → 具身场景」建立画面，再沿辐射臂记忆例词，最后用「亦见」追踪跨组联系。

A. 否定与缺失

neg- — say no / deny / nullify

变体形态：neg- / negat-

具身场景：想象一个法官用力敲下锤子——这一声否定取消了一切。neg 就是那个宣判的否决。

单词 词义 词根拆解
negate 否定、取消 neg 直接出现
negative 否定的 neg + ative
abnegation 克己、放弃 ab（离）+ neg，把自己否定掉
renegade 叛徒 re（再）+ neg，再次说不 → 背叛
renege 食言 re + neg，反口否认约定

🔗 亦见：nihil-（虚无）　a-/an-（缺失）

nihil- — nothing / zero

变体形态：nihil- / nil-

具身场景：数学课上老师在黑板写下一个大大的 0，旁边标注 nihil——一切归零。annihilate 就是把对方化成那个零。

单词 词义 词根拆解
nihilism 虚无主义 nihil = 一切皆无
annihilate 歼灭 ad（到）+ nihil，化为零
nil 零 nihil 缩短形

🔗 亦见：neg-（否定）　vac-（空）

B. 运动与路径

ced-/cess- — go / move / yield

变体形态：ced- / cede- / cess-

具身场景：人群中有人主动让开一步——那一步就是 cede。身体向后走，心理上的让步同时发生。recede 是退潮，concede 是认输那一刻。

单词 词义 词根拆解
precede 领先于 pre（前）+ cede，走在前面
recede 退缩、减退 re（回）+ cede，走回去
secede 脱离 se（分开）+ cede，走离群体
concede 让步、承认 con（共同）+ cede，一起往后走
accede 同意、就任 ac（趋向）+ cede，走向对方立场
concession 让步、特许 con + cess + ion，名词形
incessant 不停的 in（不）+ cess，停不下来的走
predecessor 前任 pre + de + cess，先走离去的人

🔗 亦见：gress-（步行）　vad-（走）

fug-/fugit- — flee / escape

变体形态：fug- / fugit-

具身场景：雨夜，一个 fugitive 在街巷奔跑，最终推开一扇门——门后就是 refuge。subterfuge 是他在逃跑路上想出来的诡计。

单词 词义 词根拆解
fugitive 逃亡者 fug + itive，逃跑的人
refuge 避难所 re（回）+ fug，逃回去的地方
refugee 难民 refuge 的人
subterfuge 诡计、借口 subter（在下）+ fug，从下面逃掉 → 暗中逃脱 → 诡计
fugue 神游、赋格 逃离现实或主题再逃回
centrifugal 离心的 centri（中心）+ fug，逃离中心

🔗 亦见：err-（游荡）　vad-（走）

sal-/sil-/sult- — leap / jump

变体形态：sal- / sil- / sult- / sali-

具身场景：猫从墙头跃起——那个弹起的瞬间就是 sal。最显眼的那块颜色跳进你眼睛，叫 salient。desultory 是像跳蚤一样跳来跳去，没有方向。

单词 词义 词根拆解
salient 显著的、突出的 sal + ient，跳出来的
resilient 有弹性的 re（回）+ sil，跳回来
resilience 韧性 弹回来的能力
exult 欢腾 ex（出）+ sult，跳出来庆祝
insult 侮辱 in（冲向）+ sult，跳到对方脸上
desultory 漫无目的的 de（离）+ sult，跳来跳去没方向
somersault 翻跟斗 somer + sault，向上跳翻

🔗 亦见：cliv-（斜坡/倾向）　scend-（攀升）

curr-/curs-/cour- — run / flow rapidly

变体形态：curr- / curs- / cour- / cors-

具身场景：河流奔涌，水是 current；顺流而下的消息叫 discourse；跑得太快只扫了一眼，就是 cursory。precursor 是提前跑来报信的人。

单词 词义 词根拆解
current 水流、当前的 curr，正在流动
cursor 光标 curs，滑动跑动之物
cursory 草率的 curs + ory，跑过去没细看
precursor 前驱、先兆 pre（前）+ curs，提前跑来的
discourse 论述、交谈 dis（四方）+ cour，思路四处奔流
recourse 求助、诉诸 re（回）+ cour，跑回去寻求
incursion 突袭 in（进入）+ curs，跑进去
excursion 短途旅行 ex（出）+ curs，跑出去一趟

🔗 亦见：fug-（逃）　vad-（走）

C. 抓取与持有

cap-/cept-/cip- — take / seize / receive

变体形态：cap- / capt- / cept- / cip- / ceiv-

具身场景：伸出手，抓住——这个动作的核心是 cap。抓住知识叫 concept；拦住信号叫 intercept；接受礼物叫 reception。手心朝上是接，朝下是抓。

单词 词义 词根拆解
capture 捕获 capt，抓住
concept 概念 con（一起）+ cept，把想法抓在一起
intercept 拦截 inter（中间）+ cept，在中途抓住
recipient 接受者 re（回）+ cip，接住传来的东西
receptive 善于接受的 re + cept + ive，能接住的
susceptible 易受影响的 sus（下）+ cept，被从下面抓住
anticipate 预期 anti（前）+ cip，提前抓住
incipient 初期的 in（进入）+ cip，刚开始被抓住
emancipate 解放 e（出）+ man（手）+ cip，从手中放出

🔗 亦见：ten-（持有）　prehend-（抓住）

ten-/tain-/tin- — hold / keep / maintain

变体形态：ten- / tain- / tin- / tent-

具身场景：双手握住一根绳——这就是 ten。不肯松手是 tenacious；把水关在里面是 contain；一直撑着是 sustain。abstain 是主动把手拿开。

单词 词义 词根拆解
retain 保留 re（回）+ tain，拉回来握住
contain 包含 con（一起）+ tain，握在一起
sustain 支撑、维持 sus（下）+ tain，从下面撑住
tenacious 顽强的 ten + acious，握得很紧
tenacity 坚韧 ten，死不松手的品质
abstain 克制、弃权 abs（离）+ tain，把手拿开
pertinent 相关的 per（彻底）+ tin，紧扣主题
impertinent 无礼的、不相关的 im（不）+ per + tin，不紧扣 → 冒失
sustenance 食物、生计 sus + ten，维持生命的东西

🔗 亦见：cap-（抓取）　hab-（持有）

greg- — flock / herd / group

变体形态：greg- / gregar-

具身场景：想象一群羊——这是 greg。有只羊跳出羊群，显得格外触目，那就是 egregious（坏得格外显眼）。gregarious 是喜欢待在羊群里的羊。

单词 词义 词根拆解
aggregate 聚合、总计 ag（趋向）+ greg，聚拢成群
congregate 集合 con（共同）+ greg，一起聚群
segregate 隔离 se（分开）+ greg，从群里分出去
egregious 极坏的、骇人的 e（出）+ greg，跳出羊群 → 坏得显眼
gregarious 爱社交的 greg + arious，喜欢待在群体里

🔗 亦见：soc-（伙伴）　dem-（民众）

haer-/hes- — stick / cling

变体形态：haer- / hes- / her-

具身场景：胶水粘住两块木板——那种黏合感就是 haer。论点粘合成整体是 coherent；一直粘在某个信念上是 adhere。incoherent 是粘不住、散了架的。

单词 词义 词根拆解
adhere 坚守、粘附 ad（向）+ here，贴过去
inherent 固有的 in（在内）+ her，天生就粘在里面
coherent 连贯的 co（共）+ her，粘合在一起
cohesive 有凝聚力的 co + hes，粘合力强
cohesion 凝聚力 co + hes + ion
incoherent 语无伦次的 in（不）+ coher，粘不在一起

🔗 亦见：lig-（绑缚）　string-（拉紧）

D. 说话与声音

voc-/vok- — voice / call

变体形态：voc- / vok- / vocat-

具身场景：演员站在舞台中央开口——声音就是 voc。用声音叫来力量是 invoke；撤回声音是 revoke；两种声音各半说不清楚是 equivocate。

单词 词义 词根拆解
vocal 声音的、直言的 voc + al
invoke 援引、祈求 in（进入）+ vok，呼唤进来
evoke 唤起 e（出）+ vok，呼唤出来
revoke 撤销 re（回）+ vok，把声音收回去
provoke 激怒、引发 pro（向前）+ vok，对着人叫
equivocate 含糊其辞 equi（相等）+ voc，两种声音各半
vociferous 叫嚷的 voc + i + fer（带来），大声带出声音
avocation 副业 a（离）+ voc，被叫离主业的事
irrevocable 不可撤销的 ir（不）+ re + voc，叫不回来

🔗 亦见：loqu-（说话）　phon-（声音）

loqu-/locut- — speak / talk

变体形态：loqu- / locut- / loc-（说话义）

具身场景：辩论赛上，选手口若悬河——那是 eloquent。朋友间随口聊天是 colloquial；绕圈子说话是 circumlocution；一个人自言自语是 soliloquy。

单词 词义 词根拆解
eloquent 雄辩的 e（出）+ loqu，说出来很漂亮
eloquence 口才 e + loqu + ence
colloquial 口语的 col（共）+ loqu，一起说的方式
colloquium 研讨会 col + loqu，一起说话的场合
soliloquy 独白 sol（独）+ loqu，自言自语
circumlocution 迂回表达 circum（周围）+ locut，绕着说
loquacious 话多的 loqu + acious，特别爱说
interlocutor 对话者 inter（间）+ locut，说话的中间人

🔗 亦见：voc-（声音）　dic-（说）　fab-（讲述）

tac-/tic- — silent / be silent

变体形态：tac- / tic- / retic-

具身场景：会议室里所有人都明白规则，但没有一个人说出口——那条不成文的规定就是 tacit。有人天生就是 taciturn，沉默是他的默认语言。reticent 是有意把话收回去。

单词 词义 词根拆解
tacit 默示的、心照不宣的 tac + it，沉默中传达
taciturn 沉默寡言的 tac + iturn，惯于沉默
reticent 保守、不多说的 re（回）+ tic，把话收回去
reticence 沉默、保留 reticent 的名词

🔗 亦见：loqu-（说话）　fab-（讲述）

scrib-/script- — write

变体形态：scrib- / script-

具身场景：羽毛笔在羊皮纸上划过——那个动作就是 scrib。在规定范围内写是 prescribe；手写下来的稿子是 manuscript；画圈限定范围是 circumscribe。

单词 词义 词根拆解
prescribe 规定、开处方 pre（前）+ scrib，提前写下来
describe 描述 de（向下）+ scrib，把细节写下来
inscribe 题词、刻写 in（进入）+ scrib，写进去
manuscript 手稿 manu（手）+ script，手写的东西
circumscribe 限制 circum（周围）+ scrib，画圈限定
conscript 征召（入伍） con（共）+ script，一起被写进名单
nondescript 平淡无奇的 non（无）+ de + script，没什么可写的
proscribe 禁止 pro（公开）+ scrib，公告写明禁止

🔗 亦见：graph-（书写）　gram-（字符）

E. 看与判断

spec-/spect-/spic- — look / observe / see

变体形态：spec- / spect- / spic- / scop-

具身场景：侦探举起放大镜，仔细观察现场——这个凝视的动作就是 spec。从各个角度看是 perspective；四处张望保持谨慎是 circumspect；一眼就看见是 conspicuous。

单词 词义 词根拆解
inspect 检查 in（进入）+ spect，看进去
perspective 视角、透视 per（穿透）+ spect，看穿后的角度
circumspect 谨慎的 circum（周围）+ spect，四处看看再行动
conspicuous 显眼的 con（加强）+ spic，一眼就看见
inconspicuous 不显眼的 in + con + spic，看不见的
auspicious 吉祥的 au（鸟）+ spic，古罗马观鸟占卜 → 兆头好
specious 似是而非的 spec + ious，看起来好但其实不是
retrospect 回顾 retro（向后）+ spect，向后看
introspect 内省 intro（向内）+ spect，向内看

🔗 亦见：vid-（看）　cern-（区分）

cern-/cret-/crit- — separate / distinguish / judge

变体形态：cern- / cret- / crit- / cris-

具身场景：筛金子——筛网把沙和金分开，那个分开的动作就是 cern。能区分细微差别是 discerning；criterion 是判断时用来区分的那把尺子；hypocrite 是在下面偷偷评判别人却不露声色的人。

单词 词义 词根拆解
discern 辨别 dis（分开）+ cern，分开看清楚
discerning 有眼力的 discern + ing
discrete 分离的、各别的 dis + cret，被分开的
discreet 谨慎的 dis + creet，懂得区分轻重
discretion 谨慎、判断力 dis + cret + ion
criterion 标准 crit + erion，用来区分的尺子
criteria 标准（复数） criterion 的复数
critical 批判的、关键的 crit + ical，做出区分判断的
hypocrite 伪君子 hypo（下）+ crit，在下面暗中评判别人

🔗 亦见：jud-（判断）　arbit-（裁定）

cogn-/gnos- — know / recognize

变体形态：cogn- / gnos- / gnor- / not-（知道义）

具身场景：老朋友在人群中突然认出你——那个"认出"的瞬间就是 cogn。agnostic 是不肯确认神是否存在；ignore 是假装没认出来；incognito 是故意不让人认出。

单词 词义 词根拆解
cognition 认知 cogn + ition
recognize 认出 re（再次）+ cogn，再次知道
agnostic 不可知论的 a（无）+ gnos，不知道是否有神
diagnose 诊断 dia（穿透）+ gnos，看穿找出病因
prognosis 预后 pro（前）+ gnos，提前知道走向
ignore 忽视 i + gnor，假装不认识
ignorant 无知的 ignor + ant
incognito 隐姓埋名地 in（不）+ cogn，不被认出
cognizant 知晓的 cogn + izant，意识到

🔗 亦见：sci-（知识）　soph-（智慧）

F. 情感与意志

path-/pathy- — feeling / suffering

变体形态：path- / pathy- / pass-（受苦义）

具身场景：医院走廊，一位医生握住病人的手——那种感同身受就是 empathy。完全感受不到叫 apathy；感受到痛苦叫 pathos；感受方向相反叫 antipathy。

单词 词义 词根拆解
empathy 共情 em（进入）+ path，进入他人的感受
sympathy 同情 sym（共同）+ path，感受相同
apathy 冷漠 a（无）+ path，没有感受
antipathy 反感 anti（反）+ path，感受对立
pathos 悲情 path，激起怜悯的感受
pathology 病理学 path（苦）+ logy，研究痛苦/疾病
sociopath 反社会人格者 socio + path，社交情感缺失

🔗 亦见：sens-（感觉）　anim-（精神）

fid- — faith / trust

变体形态：fid- / fide- / feder-

具身场景：握手——两人的手握在一起就是信任的具体形态。confident 是对自己的信任；perfidious 是把信任彻底穿透背叛；bona fide 是手握着真心。

单词 词义 词根拆解
fidelity 忠诚 fid + ity
confident 自信的 con（共）+ fid，和自己的心在一起
confide 倾诉、信任 con + fid，把信任放进去
perfidious 背信弃义的 per（穿透）+ fid，刺穿信任
perfidy 背叛 per + fid + y
infidel 异教徒 in（不）+ fid，不信仰的人
fiduciary 受托人的 fid + uciary，被信任管理财产
bona fide 真诚的、真实的 bona（好）+ fide，真正的信任
affidavit 宣誓书 af + fid，发誓表示信任

🔗 亦见：cred-（相信）　ver-（真实）

anim- — breath / spirit / life-force

变体形态：anim- / anima-

具身场景：吹一口气，泥土变成了活人——anim 就是那口气。magnanimous 是精神宏大到能容纳别人；pusillanimous 是精神小到只顾自己；equanimity 是精神平衡不动如山。

单词 词义 词根拆解
animate 赋予生命、使动起来 anim + ate
inanimate 无生命的 in（无）+ anim
magnanimous 宽宏大量的 magn（大）+ anim，精神宏大
pusillanimous 懦弱的 pusill（小）+ anim，精神渺小
animosity 敌意 anim + osity，精神对准对方的力量
equanimity 平静 equi（平）+ anim，精神平衡
unanimous 一致同意的 un（一）+ anim，一个精神

🔗 亦见：psych-（心灵）　spir-（呼吸）

plac-/pleas- — please / calm / satisfy

变体形态：plac- / pleas- / plais-

具身场景：把波浪拍平——让海面平静就是 placid 的感觉。安抚愤怒的人是 placate；implacable 是怎么拍都拍不平的浪；complacent 是只让自己满意、停在风平浪静里不再前进。

单词 词义 词根拆解
placid 平静的 plac + id，被抚平的
placate 安抚 plac + ate，使平静
implacable 无法安抚的 im（不）+ plac，平静不了
complacent 自满的 com（共）+ plac，让自己满意
complacency 自满 complacent 的名词
please 使高兴 pleas，使满足
pleasant 令人愉快的 pleas + ant
displease 使不悦 dis + please

🔗 亦见：gratif-（满足）　vol-（意愿）

G. 善恶与法律

sanct- — holy / sacred / inviolable

变体形态：sanct- / sacr- / sacros-

具身场景：教堂里那道光——神圣不可侵犯就是 sanct。用神圣权威批准叫 sanction（但也可反转成制裁）；sacrilege 是把圣物拿走；sanctimonious 是穿着神圣外衣的人，但里面是空的。

单词 词义 词根拆解
sanctity 神圣 sanct + ity
sanction 批准；制裁 sanct + ion，以神圣权威执行
sanctimonious 伪善的 sanct + imonious，假装神圣
sanctuary 圣所、避难所 sanct + uary，神圣之地
sacrilege 亵渎 sacr + i + leg（取走），拿走神圣之物
consecrate 使神圣 con（加强）+ sacr + ate
desecrate 亵渎 de（去除）+ sacr + ate，去除神圣

🔗 亦见：bene-（善）　culp-（过错）

ver- — true / truth

变体形态：ver- / verit-

具身场景：法庭上证人把手放在圣经上——那一刻的真实就是 ver。verify 是去核实；verdict 是说出真相；verisimilitude 是像真的一样——但只是像。

单词 词义 词根拆解
verify 核实 ver + ify，使其真实
veracity 诚实、真实性 ver + acity
veracious 诚实的 ver + acious
verdict 裁决 ver + dict（说），说出真相
verisimilitude 逼真 veri + simil（相似），看起来像真的
aver 断言 a + ver，坚持说是真的

🔗 亦见：fid-（信任）　prob-（证明）

culp- — fault / blame

变体形态：culp- / culpat-

具身场景：法官指着被告——那个指控的手指，指向的就是 culp（过错）。洗脱罪责是 exculpate；自认过失是 mea culpa；应受指责的是 culpable。

单词 词义 词根拆解
culpable 应受责备的 culp + able，有过错的
culprit 罪犯 culp + rit，有过错的人
exculpate 开脱 ex（去除）+ culp，去除过错
inculpate 归罪于 in（加上）+ culp，给人加上过错
mea culpa 我的过失 mea（我的）+ culpa，认罪词

🔗 亦见：sanct-（神圣/制裁）　pun-（惩罚）

H. 形态与变化

vert-/vers- — turn

变体形态：vert- / vers-

具身场景：旋转门——每推一次，方向变了，意思也变了。转向反对是 controversy；能向多个方向转是 versatile；转而离开是 avert；从底下转翻是 subvert。

单词 词义 词根拆解
convert 转变 con（共）+ vert，一起转向
divert 转移 di（分开）+ vert，转到别处
avert 避开 a（离）+ vert，转离开
revert 恢复原状 re（回）+ vert，转回来
subvert 颠覆 sub（下）+ vert，从底下转翻
versatile 多才多艺的 vers + atile，能向多个方向转
controversy 争议 contra（反）+ vers，相互转向反对
adversary 对手 ad（对）+ vers，转向对着你的人
inadvertent 无意的 in + ad + vert，没注意到转过来
perverse 悖逆的 per（彻底）+ vers，彻底转反

🔗 亦见：trop-（转向）　mut-（变化）

plic-/plex-/pli- — fold / bend / intertwine

变体形态：plic- / plex- / pli- / ploy- / ply-

具身场景：折纸——每折一层，结构更复杂。把意思折进去藏起来是 implicit；折叠多层纠缠不清是 complicated；展开来清楚说明是 explicit；duplicity 是折成两面、言行不一。

单词 词义 词根拆解
complicate 使复杂 com（共）+ plic，折叠在一起
implicit 隐含的 im（进入）+ plic，折进去没说出
explicit 明确的 ex（出）+ plic，展开说清楚
perplex 使困惑 per（彻底）+ plex，彻底折乱了
supplicate 恳求 sup（下）+ plic，折身跪地
duplicity 两面派 du（二）+ plic，折成两面
complicit 共谋的 com + plic，折在一起参与
implicate 牵连 im + plic，被折叠进去
replicate 复制 re（再）+ plic，再折一遍

🔗 亦见：greg-（群体）　nect-（连接）

I. 生命与身体

gen-/gener- — birth / produce / kind

变体形态：gen- / gener- / gon- / gin-

具身场景：种子破土而出——那个诞生的瞬间就是 gen。同一批种子长出的是同类（genus）；从一个来源产生多种形态是 generate；congenital 是出生时就带来的。

单词 词义 词根拆解
generate 产生 gen + erate
progeny 后代 pro（向前）+ gen，向前生产出来
genesis 起源 gen + esis，诞生
genus 属（生物分类） gen + us，同一来源的类别
homogeneous 同质的 homo（同）+ gen，同一来源
heterogeneous 异质的 hetero（异）+ gen，不同来源
congenital 先天的 con（共）+ gen，出生时就带来
degenerate 退化 de（向下）+ gen，向下产出
regenerate 再生 re（再）+ gen，再次产生
ingenious 有独创性的 in（内）+ gen，天生聪慧的

🔗 亦见：nasc-（出生）　viv-（生命）

mort- — death

变体形态：mort- / mor- / mori-

具身场景：沙漏的最后一粒沙——mort 是时间终止的那一刻。mortify 是让人脸面死去；moribund 是正在死的状态；mortgage 字面是"死亡担保"，还清才死的合约。

单词 词义 词根拆解
mortal 会死的、致命的 mort + al
immortal 不朽的 im（不）+ mort
mortality 死亡率 mort + ality
moribund 垂死的 mori + bund，正在死的
mortify 使难堪 mort + ify，使脸面死去
mortuary 太平间 mort + uary，死人待的地方
mortgage 抵押 mort（死）+ gage（担保），还清才死的合约
postmortem 验尸；事后检讨 post（后）+ mort，死后检查

🔗 亦见：necro-（死体）　viv-（生命）

J. 光与火

luc-/lum-/lus- — light / shine

变体形态：luc- / lum- / lus- / lustr-

具身场景：黑暗房间里，有人点亮一盏灯——luc 就是那道光。lucid 是像光一样透明清晰；pellucid 是光完全穿透、一片澄明；lackluster 是没有光泽的暗淡。

单词 词义 词根拆解
lucid 清醒的、清晰的 luc + id，像光一样透明
elucidate 阐明 e（出）+ luc，把光带出来
illuminate 照亮、启发 il + lum，让光进入
luminous 发光的 lum + inous
translucent 半透明的 trans（穿透）+ luc，光穿得过但不全透
illustrious 著名的 il + lustr，被光照耀的
lackluster 无光泽的、平淡的 lack + luster，缺少光泽
pellucid 清澈的、清晰的 per（穿透）+ luc，光完全穿透

🔗 亦见：flagr-（燃烧）　cand-（发光）

flagr- — burn / blaze

变体形态：flagr- / flam- / flagrant-

具身场景：火焰冲天——flagr 是那个不掩饰的燃烧。罪行像火焰一样明目张胆是 flagrant；大火蔓延失控是 conflagration；当众被抓是 in flagrante（在火焰之中）。

单词 词义 词根拆解
flagrant 公然的、明目张胆的 flagr + ant，像火焰一样明显
conflagration 大火 con（加强）+ flagr，火焰汇聚
deflagrate 爆燃 de（向下）+ flagr，火向下烧
in flagrante 当场 在燃烧中 → 现行犯
flamboyant 炫目的 flam（焰）+ boyant，像火焰飘动
inflame 激怒、点燃 in + flam，点火

🔗 亦见：luc-（光）　cand-（白热）

K. 流动与物质

flu-/flux- — flow

变体形态：flu- / flux- / fluct-

具身场景：河流不停流淌——flu 是那股流动。话语流畅是 fluent；财富流向你是 affluent；流得太多溢出来是 superfluous；涌入是 influx。

单词 词义 词根拆解
fluent 流利的 flu + ent，流动自如
fluid 液体、流动的 flu + id
influx 涌入 in（进入）+ flux，流进来
efflux 流出 ef（出）+ flux
affluent 富裕的 af（向）+ flu，财富流向你
confluent 汇流的 con（共）+ flu，一起流
fluctuate 波动 fluct + uate，流动起伏
superfluous 多余的 super（超过）+ flu，流得太多溢出
effluvium 恶臭 ef + fluv，流出来的气体

🔗 亦见：und-（波浪）　hydr-（水）

L. 制作与力量

fac-/fact-/fic-/fect- — make / do

变体形态：fac- / fact- / fic- / fect- / feas-

具身场景：工匠的双手——所有制造的动作都从 fac 来。factory 是大规模做的地方；efficacy 是做出效果；facile 是做起来太容易、因此缺乏深度。

单词 词义 词根拆解
factory 工厂 fact + ory，制造的地方
artifact 人工制品 art（技艺）+ fac，手工做的
efficacy 功效 ef（出）+ fic，做出效果
efficient 高效的 ef + fic + ient
proficient 熟练的 pro（前）+ fic，在前面做得好
deficient 不足的 de（离）+ fic，做不到位
facile 肤浅的 fac + ile，做起来太容易了 → 不深刻
affect 影响 af（向）+ fect，做向某人
infect 感染 in（进入）+ fect，做进去
confection 糖果、制作物 con（共）+ fect，一起做成的东西

🔗 亦见：oper-（工作）　labor-（劳作）

duc-/duct- — lead / draw

变体形态：duc- / duct-

具身场景：向导走在最前面——duc 是那个引路的人。educate 是把潜力从内引出来；abduct 是强行引离；deduce 是从前提向下引出结论。

单词 词义 词根拆解
conduct 引导、行为 con（共）+ duct，一起引领
deduce 推断 de（向下）+ duc，向下引出结论
induce 诱导 in（进入）+ duc，引进去
seduce 引诱 se（旁侧）+ duc，引向旁边
abduct 绑架 ab（离）+ duct，强行引离
educate 教育 e（出）+ duc，把潜力引出来
aqueduct 引水渠 aqu（水）+ duct，引水的管道
ductile 延展的、顺从的 duct + ile，可以被引导的
reduce 减少 re（回）+ duc，引回更小
introduce 介绍、引入 intro（向内）+ duc，引进来

🔗 亦见：tract-（拉）　pel-（推）

tract- — draw / pull

变体形态：tract- / trah-

具身场景：拖拉机拉着犁——tract 是那个拉的力量。attract 是把你拉过来；extract 是从里面拉出来；protract 是把时间拉长；intractable 是拉不动的。

单词 词义 词根拆解
attract 吸引 at（向）+ tract，拉过来
extract 提取 ex（出）+ tract，拉出来
protract 延长 pro（向前）+ tract，拉长
retract 收回 re（回）+ tract，拉回去
distract 分心 dis（分开）+ tract，拉向别处
detract 贬低 de（向下）+ tract，向下拉
tractable 顺从的 tract + able，可以被拉动的
intractable 难以控制的 in + tract，拉不动
abstract 抽象的；摘要 abs（离）+ tract，从具体中拉离

🔗 亦见：duc-（引导）　pel-（推）

M. 高级词汇专项

sed-/sid-/sess- — sit / settle

变体形态：sed- / sid- / sess- / set-

具身场景：僧侣在蒲团上打坐，一坐就是几小时——那种持续坐住的状态就是 sed。assiduous 是一直坐在工作旁；insidious 是坐在暗处静静等待；obsess 是一直坐在你对面。

单词 词义 词根拆解
sedentary 久坐的 sed + entary，习惯坐的
reside 居住 re（回）+ sid，坐回去住下
preside 主持 pre（前）+ sid，坐在前面
president 总统、主席 pre + sid + ent，坐在前面的人
assiduous 勤奋的 as（在旁）+ sid，一直坐在工作旁
insidious 阴险的 in（内）+ sid，坐在里面悄悄等
session 会议 sess + ion，坐下来的时段
obsess 困扰 ob（对着）+ sess，一直坐在你对面
subside 平息 sub（下）+ sid，向下沉坐

🔗 亦见：sta-（站立）　ten-（持有）

limin-/limen- — threshold / boundary

变体形态：limin- / limen-

具身场景：门槛——站在门槛上就是处于两个世界的边界。subliminal 是在意识门槛之下；preliminary 是还在正式门槛之前；eliminate 是把人推出门槛、彻底去除。

单词 词义 词根拆解
preliminary 初步的、预备的 pre（前）+ limin，在门槛之前
subliminal 潜意识的 sub（下）+ limin，门槛之下
eliminate 消除 e（出）+ limin，把人推出门槛
liminal 过渡的 limin + al，处于门槛上

🔗 亦见：fin-（边界/终止）　term-（界限）

rog- — ask / request

变体形态：rog- / rogat-

具身场景：古罗马官员在广场上向民众提问——rog 就是那个公开询问的动作。arrogant 是向自己要求太多；interrogate 是来回追问；prerogative 是提前被赋予提问权力，即特权。

单词 词义 词根拆解
interrogate 审问 inter（中间）+ rog，来回追问
arrogant 傲慢的 ar（向）+ rog，向自己要求太多
arrogate 擅自占用 ar + rog，把权力要到自己手里
derogate 贬低 de（向下）+ rog，向下提问/否定
derogatory 贬义的 de + rog + atory
abrogate 废除 ab（离）+ rog，停止要求 → 废除
prerogative 特权 pre（前）+ rog，提前被赋予要求的权力
surrogate 代理人、替代 sur（代替）+ rog，替代提问者

🔗 亦见：jur-（法律）　dic-（说）

rud- — raw / untrained

变体形态：rud- / rudi-

具身场景：未经雕琢的原石——rud 是那种粗糙的原始状态。erudite 是去掉粗糙、打磨出来的博学；rudimentary 是还停留在粗糙的基础阶段。

单词 词义 词根拆解
rudimentary 基础的、初级的 rud + imentary，还在粗糙阶段
rudiment 基础、初步 rud + iment
rude 粗鲁的 rud + e，未经打磨
erudite 博学的 e（去除）+ rud，磨去粗糙
erudition 博学 erudite 的名词

🔗 亦见：soph-（智慧）　doc-（教）

oner- — burden / load

变体形态：oner-

具身场景：一个人背着沉重的石头——oner 是那块石头的重量。onerous 是石头重得压垮人；exonerate 是卸下石头，无罪释放。

单词 词义 词根拆解
onerous 繁重的 oner + ous，充满负担的
exonerate 免除责任 ex（去除）+ oner，卸掉重担
onus 责任 on + us，要背的东西

🔗 亦见：grav-（重）　labor-（劳作）

附录：高频失分词根对照表

SAT 阅读中最容易因词根混淆导致失分的 20 对。每对给出核心区别和记忆口诀。

1. cred-（相信）vs crit-/cern-（区分/判断）

核心区别：credulous（轻信）vs critical（批判）——前者全盘接受，后者分辨是非

口诀：credulous 的人 cred 一切；critical 的人先 cern 再 cred

2. flu-（流动）vs fug-（逃跑）

核心区别：fluent（流利）vs fugitive（逃亡）——流动是自然的，逃是被迫的

口诀：flu 往前流，fug 往外逃。superfluous 是流溢的，subterfuge 是逃脱的诡计

3. vert-（转）vs voc-（声音/呼叫）

核心区别：avert（转开）vs evoke（唤起）——一个转身，一个开口

口诀：vert 靠身体转；voc 靠声音动。controversy 是转向争论，provoke 是用声音激起

4. spec-（看）vs spir-（呼吸）

核心区别：inspect（检查）vs inspire（激励）——一个用眼，一个靠气息

口诀：spec 看表面；spir 吸进去。conspicuous 是看得见，inspiration 是吸入的灵感

5. sed-（坐）vs sequ-（跟随）

核心区别：sedate（镇静）vs sequel（续集）——一个静止，一个跟进

口诀：sed 让人坐稳；sequ 让人跟上。assiduous 是坐在工作旁，obsequious 是过度跟随

6. cap-（抓取）vs clud-/clus-（关闭）

核心区别：capture（捕获）vs exclude（排除）——一个抓进来，一个关出去

口诀：cap 用手抓；clud 用门关。receptive 是愿意接，recluse 是把自己关起来

7. gen-（产生/出生）vs greg-（群体）

核心区别：generate（产生）vs aggregate（聚合）——一个是来源，一个是聚集

口诀：gen 是生出来的；greg 是凑在一起的。genesis 是起点，segregate 是分开群体

8. luc-（光）vs loqu-（说话）

核心区别：lucid（清晰）vs loquacious（话多）——一个是透明，一个是多言

口诀：luc 让你看清楚；loqu 让你听不停。elucidate 是用光照亮，circumlocution 是绕着说

9. mort-（死亡）vs morph-（形态）

核心区别：mortal（会死的）vs metamorphosis（变形）——一个是终结，一个是变化

口诀：mort 走向终点；morph 改变外形。moribund 是快死了，amorphous 是没有固定形状

10. path-（感受/苦）vs pat-（pati-）（忍受）

核心区别：empathy（共情）vs patience（耐心）——同根异义，一个感受，一个忍受

口诀：empathy 是感同身受；patience 是忍住感受。apathy 是无感，impatient 是忍不住

11. tract-（拉）vs trac-（踪迹义）（注意区分）

核心区别：extract（提取）vs trace（追踪）——拉和踪迹形近但根不同

口诀：tract 的核心是拉：attract 拉过来，retract 拉回去，intractable 是拉不动的

12. fid-（信任）vs fac-/fic-（做）

核心区别：confident（自信）vs proficient（熟练）——前者靠信任，后者靠做

口诀：fid 在心里；fac 在手上。perfidious 是刺穿信任，efficacious 是做出效果

13. anim-（精神/生命）vs ann-（年）

核心区别：animate（赋予生命）vs annual（年度的）——形近义远，anim 有 i

口诀：anim 有 i 是精神；ann 没有 i 是年份。equanimity 是精神平衡，perennial 是多年生的

14. vert-（转）vs ver-（真实）

核心区别：subvert（颠覆）vs verify（核实）——一个转翻，一个求真

口诀：vert 靠转动；ver 靠真相。perverse 是转向错误，veracious 是说真话

15. sanct-（神圣）vs sens-/sent-（感受）

核心区别：sanctuary（圣所）vs sentiment（情感）——一个神圣权威，一个内心感受

口诀：sanct 是外部权威加持的；sent 是内心自发的。sanction 是授权，dissent 是感受不同

16. greg-（群体）vs grad-/gress-（步行）

核心区别：egregious（极坏的）vs transgress（违反）——一个跳出群体，一个跨越界限

口诀：greg 是关于群体的；gress 是关于走的。congregate 是群聚，progress 是向前走

17. plac-（安抚）vs plic-/plex-（折叠）

核心区别：placate（安抚）vs complicate（使复杂）——一个平静，一个折叠

口诀：plac 让波浪平息；plic 把东西折进去。implacable 是无法平息，explicit 是展开说清楚

18. haer-/hes-（粘连）vs aer-（空气）

核心区别：adhere（坚守）vs aerial（空中的）——形近但词根完全不同

口诀：haer/hes 是粘；aer 是空气。coherent 是粘合一致，aerobic 是有氧的

19. cand-（发光/白热）vs cant-（唱/倾斜）

核心区别：candid（坦率）vs recant（撤回声明）——一个是透明，一个是声音收回

口诀：cand 像白光一样透明；cant 是口头的声音。incandescent 是白炽的，incantation 是咒语

20. limin-（门槛）vs liber-（自由）

核心区别：subliminal（潜意识的）vs liberate（解放）——一个在门槛下，一个越过边界

口诀：limin 是门槛这个点；liber 是摆脱约束的状态。preliminary 是门槛之前，deliberate 是自由思考
